# Nicolau Assistance — Web

Aplicação web estática com Supabase Auth + PostgreSQL. Consulte `LEIA-ME.txt` para configuração completa, criação do administrador, deploy da Edge Function e publicação.

**Configuração pública:** `config.supabase.json` contém apenas Project URL, Publishable Key e UID do administrador. Nunca adicione a `service_role` ao frontend.
\n\nPWA: inclui manifest, Service Worker, ícones do logótipo enviado e botão para instalar no ecrã inicial. Requer publicação HTTPS. Ver `LEIA-ME.txt`, secção 7.\n
